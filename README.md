# Bitácoras de Seguimiento

## Descripción del proyecto

Este proyecto consiste en el desarrollo de un sitio web para presentar y organizar las bitácoras de seguimiento realizadas durante el proceso de aprendizaje. El sitio permite consultar información general del proyecto, conocer las reglas establecidas y acceder a las diferentes bitácoras organizadas por año, mes, semana y día.

El objetivo principal es que la información quede organizada de una manera clara y fácil de consultar, utilizando una estructura de páginas HTML conectadas entre sí mediante enlaces de navegación.

## Estructura del proyecto

El sitio cuenta con tres vistas principales:

### 1. Inicio

Es la página principal del proyecto. En esta vista se presenta el sitio y se ofrece la navegación hacia las demás secciones.

### 2. Información

En esta sección se encuentra información relacionada con la persona y quien desarrollo el proyecto. Su función es brindar un contexto general de datos antes de consultar las bitácoras.

### 3. Bitácoras

Esta parte permite acceder a las bitácoras de seguimiento. Las actividades están organizadas por año, mes y semanas, y cada día cuenta con su propio archivo HTML. De esta manera, el usuario puede seleccionar una semana y posteriormente consultar la bitácora correspondiente a cada día.

## Navegación

Las diferentes páginas del proyecto están conectadas mediante un menú de navegación, lo que permite desplazarse fácilmente entre las secciones de Inicio, Información, Reglas y Bitácoras. Las bitácoras también cuentan con enlaces que permiten acceder directamente a cada actividad registrada de cada semana correspondiente al mes.

## Accesibilidad y semántica

Durante el desarrollo del proyecto se tuvieron en cuenta algunas prácticas básicas de accesibilidad y HTML semántico.
Se utilizaron etiquetas HTML que permiten organizar mejor el contenido, como:

* header: para la cabecera.
* nav: para el menú de navegación.
* main: para el contenido principal.
* section: para dividir la información en diferentes secciones.
* h1, h2 y h3: para establecer una jerarquía clara de títulos.
* ul y li: para organizar listas.
* a: para crear enlaces de navegación.
* html: Indica que comienza un documento HTML.
* table: Crea una tabla.
* head: Contiene información de configuración de la página.
* footer: Representa el pie de página.
* body: Contiene todo el contenido visible de la página.
* href: Indica la dirección a la que lleva un enlace. (atributo)
* th: Crea una celda de encabezado en una tabla. 
* tr: Crea una fila en una tabla.
* td: Crea una celda normal en una tabla.

También se buscó mantener una estructura clara y ordenada en las páginas, utilizando textos comprensibles y enlaces que permiten identificar fácilmente a dónde dirige cada opción.

## Organización del repositorio

El proyecto se encuentra organizado en carpetas para facilitar la ubicación de los diferentes archivos y bitácoras.
Las bitácoras están organizadas siguiendo una estructura de año, mes, semana y día, permitiendo mantener un orden en la información y facilitar su consulta.
