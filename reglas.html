Guía de llenado por columna

Columna Descripción y Formato Esperado
ID Número consecutivo unico para cada actividad.
Timestamp Fecha y hora exacta en la que se registra o ejecuta la actividad (formato AAAA-MM-DD HH:MM).
Autoría Nombre o iniciales del aprendiz responsable de ejecutar la actividad.
Objeto Técnico Descripción técnica objetiva verificable y concreta de lo ejecutado y su alcance real.
Evidencia de Ejecución URL del commit enlace al Pull Request captura de pantalla o documento entregable.
Impedimentos / Blockers Descripción técnica del error o impedimento. Si no hubo problemas escribir: 'Sin impedimentos operativos'.
Plan de Acción Acción correctiva tomada próxima tarea programada o paso para desbloquear la actividad.
